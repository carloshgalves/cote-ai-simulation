# Character Fidelity

For each focal character build:
- stable traits and priorities;
- capability profile by dimension, not one intelligence score;
- typical decision patterns;
- social/linguistic tendencies;
- motives and constraints;
- blind spots and failure modes;
- evidence references for each important claim.

Create eval scenarios in three groups:
1. **positive cases** — canonical tendency should appear;
2. **contrast cases** — two characters should respond differently;
3. **anti-cases** — a superficially smart/dramatic response would be out of character.

Fidelity is not exact quote imitation. Prefer decisions, priorities and information use over prose mimicry.

For Kiyotaka specifically, never encode competence as privileged access to secrets. Test high-quality inference from partial evidence and willingness *not* to reveal ability when that better matches goals.
