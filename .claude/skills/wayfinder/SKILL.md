# Wayfinder

Create a decision map rather than a giant implementation checklist.

1. Define the destination in observable terms.
2. Identify blocking decisions first.
3. Turn each blocking decision into a small ticket/research task with evidence required to close it.
4. Mark dependency edges.
5. Prefer tracer bullets that cross engine → agent → exam → eval over horizontal layers.
6. Re-plan when a decision invalidates downstream assumptions.

Never generate dozens of tickets around an unresolved framework or domain choice.
