Execução independente

O experimento Go Kokkuri possui seu próprio motor e journal. Os demais jogos estão no runtime de referência. Este catálogo não injeta personagens, regras ou segredos no save escolar.

go run ./cmd/tomodachi-local --scripted --out /tmp/tg-owner.json

O modo scripted é um teste determinístico, não uma avaliação de LLM.

Avançar tempo simulado

Os lotes preservam cada ciclo no journal. Decisões sociais, compromissos e exames mantêm resolução detalhada. O modo adaptativo chama o LLM quando necessário; somente rotinas para antes da inferência. Pausar interrompe após o ciclo ou lote em andamento.
