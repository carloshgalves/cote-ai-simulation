# Actors

Actor files are canonical entity stubs: identifier, name/aliases, class membership and provenance.

The six focal V0 actors now have stubs so character evidence can reference stable actor ids. These
stubs are not dossiers and do not contain cognition state, physical capacity, dynamic relationships,
or future simulation history.

Behavioral dossiers live under `data/canon/characters/`; passage-level paraphrases live under
`data/canon/evidence/characters/`. All current actor data remains subject to the canon provenance
policy and is not promoted to `VERIFIED` without direct Tier 0–1 checking.
