# Character evidence packs

This directory contains the declarative V0 evidence layer for focal characters.

A pack is **not** an agent prompt and **not** executable cognition. It records small behavioral
assertions, goals, capability evidence, decision patterns, blind spots, initial private knowledge,
and the distinction between latent capability and likely manifestation.

## Horizon

V0 is anchored at `Y1_START`.

Evidence from later volumes may be used only to support a capability or tendency that can plausibly
pre-exist the horizon. Such evidence is marked `FUTURE_EVIDENCE_ONLY`; it never becomes a memory,
belief, relationship event, goal, or secret learned retroactively.

## Epistemic status

The current canon baseline has not yet been checked by a human against Tier 0–1 text. Therefore V0
pack assertions are `UNVERIFIED`, `INFERRED`, `INTERPRETATION`, or `UNKNOWN`; none are
`VERIFIED`.

Physical capacity is deliberately absent. The shared feat corpus and Embodiment domain own physical
capacity; character packs may only describe behavioral choices around revealing or withholding
ability when supported by evidence.
