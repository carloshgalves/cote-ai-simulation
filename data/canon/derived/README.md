# Derived

Artefatos **gerados**, não editados à mão. Snapshots compilados e validados, identificados por hash de conteúdo, consumidos pelo engine.

O hash entra nos metadados do run para reprodutibilidade.

Um claim só compila para cá se: `epistemic_status: VERIFIED`, suporte de tier adequado, `engine.binds_to` preenchido e nenhum conflito aberto que o bloqueie. Hoje nada satisfaz essas condições, e por isso este diretório está vazio.
