# Exams

Cânone dos exames especiais: participantes, período, regras públicas, papéis secretos, canais de informação e pontuação, como claims datados.

Insumo futuro do `ExamSpec` executável descrito em `docs/architecture/exams.md`. Um exame só é modelado depois que `oq.exam.disclosure-model` estiver respondida — sem o modelo de divulgação não há como manter o conhecimento dos agentes limitado durante o exame.
