# Y1 canon events

Linha de eventos canônica do primeiro ano, datada em tempo de história.

Serve como **referência e fonte de `known_by`**, não como roteiro. Depois do ponto de divergência, eventos daqui não podem ser injetados como memória factual dos agentes (`divergence_sensitive`). Ver ADR 0002 e `docs/canon/temporal-model.md`.
