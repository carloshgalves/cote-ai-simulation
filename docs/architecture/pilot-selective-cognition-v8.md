# Pilot V8 — selective cognition

New local journals use V8. Existing V1–V7 journals retain their replay and routing semantics; to try V8 use a new path with `-save`. The V7 default file is never migrated silently.

The same routing predicate governs provider calls, event-only advance and validation of deterministic routine provenance. FULL and LIGHTWEIGHT describe representational resolution. Neither tier automatically implies a call on completion of an ordinary activity. Direct stimuli, conversation turns, explicit recheck deadlines, active exam participants and one free-period initiative opportunity per student/day are admitted. Ordinary body alerts remain private observations and are addressed by the existing local routine. Ordinary movement no longer wakes waiting actors; recognition of a known person remains an explicit stimulus.

The daily opportunity is a provisional policy, not a measured estimate or hard daily call quota. Existing routine behavior is reused rather than redesigned in this slice. Subsequent deliveries must address heterogeneous initiative, plan continuation outside exams, richer routines and benchmark/evals. No Tomodachi Game corpus or pack changes are included.
