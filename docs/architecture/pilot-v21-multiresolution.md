# V21 bounded multiresolution

Three levels of execution: isolated private rest may consolidate two 60-minute segments (max 120, bounded by next public/exam/deadline event and physiological needs); routine-only macro batches of up to 32 ordinary rounds commit one atomic journal replacement without discarding individual rounds; any required cognition returns to detailed execution. Macro stops after material events and before model decisions; adaptive UI resumes with normal Step when needed. No simulated utterance, relationship, belief, goal or outcome is inferred from elapsed time. All normal effects, social encounters and audit receipts persist. Quiet rest is deliberately narrow: no public class, exercise, conversation, co-presence, known appointment, exam participant or active plan coalescing. V20 and earlier replay unchanged.

Calendar controls target the next or selected exam day at 08:00; all preceding events remain in the journal. Timeline counts actual dialogue, social/meeting and exam records for the selected period. No skipped-day narrative generation. The atomic macro rolls back an uncommitted batch on cancellation/error. Existing 32 MiB JSON limit and history scaling remain; a full year is not qualified. Tests cover exact macro/sequential reduction, addressed cognition stop and quiet-rest bounds. Actual Go tests, browser validation and matched cost/fidelity evaluation pending.
