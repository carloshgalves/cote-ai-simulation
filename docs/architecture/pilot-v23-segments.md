# V23 incremental persistence and controlled parallel inference

New saves keep a private immutable genesis header and hash-linked, exclusively published round batches in <save>.segments. Replay validates every segment and verifies optional full-state checkpoints every 512 rounds. Checkpoints are audit artifacts, not trusted fast-start state; replay still reconstructs the entire prefix. Copy header and sidecar together while stopped. Old saves remain monolithic. No claim of tamper resistance against a party able to rewrite all local data or crash durability across power loss (directory fsync remains outstanding).

Parallel model dispatch is bounded at three workers for two or more distinct enabled non-ChatGPT hosts. Same endpoint host and ChatGPT account serialize; fallback can choose another route while a host is occupied. Frozen state and canonical actor order remain. Provider calls may vary across runs; replay uses recorded decisions. An error retains only the canonical successful prefix, not speculative suffix decisions. A single configured provider gets no concurrency gain. Scripted benchmark opt-in: COTE_FIRST_EXAM_BENCH=1 go test -v ./internal/pilot -run TestFirstExamElapsedBenchmark. Real LLM benchmark requires operator routes and measured run; not executed in connector environment. State/event clones and all-history reporting remain scaling limits.
