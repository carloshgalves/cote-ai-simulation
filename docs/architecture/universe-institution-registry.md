# Operator universe registry

The local owner API embeds metadata from all COTE character/institution/exam packs and Tomodachi exam references. Historical associations are deliberately labeled as such. External and future actors are browsable and searchable, not enrolled, granted school powers, or injected into the agent directory. Tsukishiro remains reserved; active entry requires a causal institutional adapter. Political factions and corporations not evidenced with individual membership remain visible without invented members. All character cards use local original SVG portraits (provisional/nonofficial); selected major actors have authored style variants, the remainder are procedural, not canonical visual evidence. The library separates scheduled adaptations, excluded games and unresolved references. Real multi-agent external institution operations remain unimplemented.
