# Character fidelity evals

Golden scenarios for the Character Evidence V0 layer. These files do not invoke an LLM or define a cognition engine.

They cover positive cases, contrast cases, anti-cases, and knowledge-leakage cases. All suites use the `Y1_START` knowledge horizon. `available_information` is visible to the tested character; `withheld_world_truth` is not. Evidence refs point to paraphrased canon records under `data/canon/evidence/characters/`.

The contrast matrix describes baseline tendencies, not rigid rules; causal simulation state may change behavior.
